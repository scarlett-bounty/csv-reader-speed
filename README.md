A faster drop-in for csv-reader 1.0.0: a dependency-free ES module that reads broken CSV files and returns exactly the answer csv-reader 1.0.0 returns, but faster. Practice set 6/6 correct, about 1.97x faster than the house baseline (median wall time).

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
